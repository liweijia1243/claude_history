# Projects 页面搜索功能设计

## 背景

随着项目数量增多，Projects 页面需要一个搜索功能来快速定位目标项目。

## 方案

纯前端过滤。项目数据在页面加载时已全部获取，数量有限（通常几十个），前端 computed 过滤零延迟、零后端改动。

## 改动范围

仅修改 `web/src/views/ProjectsView.vue`，不改后端、路由或其他组件。

## 详细设计

### 新增响应式状态

- `searchQuery` (ref) — 搜索输入值

### 新增计算属性

- `filteredProjects` — 对 `projects` 按 `path` 字段实时过滤，大小写不敏感匹配

### 模板改动

1. 标题下方添加全宽搜索输入框：
   - 左侧搜索图标
   - 右侧清除按钮（输入非空时显示）
   - placeholder 文案："搜索项目路径..."
2. 项目网格遍历 `filteredProjects` 替代 `projects`
3. 标题旁数量显示匹配结果数（如 "12" → "5/12"）
4. 搜索无结果时显示空状态提示

### 风格

沿用项目现有 CSS 变量和暗色主题，与页面整体风格一致。
